GitHub Actions on the post-M6-C1 `main` commits was actually red.

For run `35423552418` on `2e976be182755025268842a3d871b430368633c0`:

- dependency install used only `".[dev]"`;
- Ruff passed;
- full pytest ended `2 failed, 6291 passed, 3 skipped`;

  `SurfaceAPIUnavailableError` because FastAPI was not installed;

Dashboard implementation, but a red default-branch CI could not be ignored as
“no CI evidence”.

invent, such as Cloudflare authorization, owner-selected hostnames/identity

interactive identity-provider login check.

live smoke requirements, manual verification sequence and explicit blocked
